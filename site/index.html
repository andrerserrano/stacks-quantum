Quantum pilot

A vault on Stacks that only a hash-based signature can open

Funds in this vault move only when the owner signs with a one-time key built from SHA-256. That check uses no elliptic curves and no lattices. It runs as an ordinary Clarity contract, so it needed no change to Stacks.

What this shows

  • The vault pays only what its hash-based key signed, and only once.
  • An attacker who holds the owner's Stacks account key cannot move the funds.
  • It took no consensus change and no new Clarity function.

What it does not

  • The transaction that carries a withdrawal is still signed with today's elliptic-curve keys.
  • Stacks blocks and signers still rely on those keys.
  • The Bitcoin backing sBTC sits behind a Taproot key. A vault does nothing for it, and the sBTC here is a test token.
  • No cryptographer has reviewed this. It holds test funds only.

How it works

One signature, checked by a contract

  1. The owner Signs a request

    On their own device, with a one-time key. The request names the amount, the recipient and the vault's next key.

  2. Any account Submits it

    Any Stacks account can carry the request to the chain and pay the fee. It has no say over the funds.

  3. The vault contract Checks the signature

    It asks a verifier contract whether the signature matches the key it holds. The verifier runs SHA-256 and nothing else.

  4. The recipient Is paid

    The vault pays who the owner signed for and switches to the next key. The old key is never used again.

    Size and cost

    What a hash-based signature costs

    The signature is larger than today's and takes more compute to check. Both stay small against what a tenure allows. A tenure is the run of Stacks blocks between two Bitcoin blocks.

    Why WOTS+ and not Lamport

    Both are one-time signatures that rest on SHA-256 alone. The vault can use either, and the run above uses both.

    • Size. A WOTS+ signature is 7.5 times smaller for about the same compute. On a blockchain, size is the cost that matters.
    • Where it leads. The schemes that let one key sign many times, XMSS and SLH-DSA, are built from WOTS+. The signature proposed for Ethereum's validators is from the same family.
    • What Lamport does better. It is simpler to explain, and more forgiving if a key is used twice by mistake.

    The path

    From one vault to a quantum-resistant Stacks

    A vault protects one layer. These are the others, in the order we would take them.

    1. Shown here
      Assets held in contracts

      Funds in a vault move only on a hash-based signature. Other contracts can use the same verifier.

    2. Next
      Accounts

      Keys that sign many times, built on the same check, and an account flow that makes them usable day to day.

      Signers and blocks

      A hash-based signature alongside the keys that approve Stacks blocks and sBTC withdrawals today.

      The Bitcoin backing sBTC
